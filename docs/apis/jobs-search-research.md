# Jobs Search source research (13 October 2026)

Scope: live offers for a third-party jobseeker app in Germany and Europe. An employer posting API is not a search-data licence. Publicly viewable pages, browser network calls, and robots allowance alone do not grant republication rights. Prices and terms below are a dated snapshot; recheck before obtaining keys or launching a commercial feed.

## Sources already integrated

| Source | Access and useful fields | Geographic and operational limit | Reuse position |
| --- | --- | --- | --- |
| [Arbeitnow](https://blog.arbeitnow.com/blog/job-board-api) | Key-free `GET https://www.arbeitnow.com/api/job-board-api?page=N`; `data[]` has title, company, HTML description, location, remote flag, types, date and listing URL. Published feed updates hourly; no server-side keyword or city search. | Germany-focused; local filtering over bounded pages means sparse matches can be missed. See [adapter notes](arbeitnow.md). | [Terms §2 and §11](https://www.arbeitnow.com/terms) must be read together. §2 gives a personal, non-commercial, transitory website-materials licence; §11 explicitly anticipates API use on another platform, requires a link to Arbeitnow and allows revocation. This is **not a blanket definitive ban**, but the interaction leaves commercial redistribution uncertain. Link each result back and resolve commercial scope before production expansion. |
| [Bundesagentur für Arbeit Jobsuche](https://www.arbeitsagentur.de/jobsuche/) | Public web app uses `GET https://rest.arbeitsagentur.de/jobboerse/jobsuche-service/pc/v6/jobs` with public `X-API-Key: jobboerse-jobsuche`; detail endpoint is `/pc/v4/jobdetails/{id}`. Supports keywords, place/radius and paging; `homeofficemoeglich` means home office possible, not fully remote. | Strong German coverage. The header and endpoints belong to the web app and are **undocumented for third parties**; they may change, throttle or restrict access without notice. Bounded live queries only. | No published general-purpose jobseeker search-data licence was established for this internal interface. Treat it as technically usable but fragile; seek a documented permission route for durable commercial reuse. |
| [Sweden JobTech JobSearch](https://data.jobtechdev.se/dataservice/jobsearch/) | Official, key-free, [CC0](https://data.jobtechdev.se/dataservice/jobsearch/) data; `GET https://jobsearch.api.jobtechdev.se/search` and `/ad/{id}` provide full descriptions and application links. | Sweden only; use country concept and verify returned country. Remote search is likelihood-based, so do not assert fully remote without stronger ad evidence. See [adapter notes](jobtech.md). | Best documented open public source here. No published numeric rate limit; bounded queries remain prudent. |
| [80,000 Hours](https://jobs.80000hours.org/) | Its logged-out board exposes a public browser-search Algolia index. The development adapter reads the board's current public search configuration and makes one bounded country-facet query, returning original listing links and short metadata only. | DE/SE currently verified; country and city tags checked locally. No documented third-party API, so the browser configuration and index can change. Remote status remains unknown. See [adapter notes](eighty-thousand-hours.md). | Its [terms](https://80000hours.org/terms-of-use/) grant no general syndication right and limit third-party redistribution. Browser-visible access is not a production licence; obtain permission before public redistribution. |
| [Hard Problems](https://www.hardproblems.com/jobs) | The impact design/product board explicitly links a first-party [RSS feed](https://www.hardproblems.com/jobs/feed.xml), filtered with `?country=Germany` or `?country=Sweden`. Development adapter returns board/original links and short metadata, not bodies. | DE/SE verified; returned location must itself name the requested country, so `Global` rows are excluded. Narrow role coverage; no salary or employment type; only explicit `Remote` is classed remote. See [adapter notes](hard_problems.md). | RSS is offered for subscription, but no general republication licence was found. Keep board attribution and source links, and clarify broader public redistribution with the board. |

## Documented APIs available after registration or agreement

| Source | Germany/EU search route and cost | Access and display constraint |
| --- | --- | --- |
| [France Travail Offres d'emploi](https://www.data.gouv.fr/dataservices/api-offres-demploi) | Official French active-offer API; filters include occupation, commune, département and contract. **Currently restricted**: its public listing says the former `pole-emploi.io` exposure is suspended pending distribution/reuse review after mass automated AI usage. Organisations must request access through France Travail's contact form. No generally available free key can be assumed. | [France Travail says](https://www.francetravail.fr/informations/informations-legales-et-conditio/conditions-generales-dutilisatio.html) partner access requires accepting its offers-reuse licence; some partner offers are omitted if their owners have not consented, and contact data is excluded. Explicitly clear the AI-app use case, licence and attribution before integration. |
| [Adzuna Search Ads](https://developer.adzuna.com/docs/search) | Country path such as `/v1/api/jobs/de/search/1` or `/fr/search/1`, with `app_id` and `app_key`; keyword/location, descriptions/excerpts, salary when supplied, and redirect URL. Default [limits](https://developer.adzuna.com/docs/terms_of_service): 25/min, 250/day, 1,000/week, 2,500/month. | Its [terms](https://developer.adzuna.com/docs/terms_of_service) permit publishing listings with specified Adzuna attribution/logo link. Other commercial, government or academic use is limited to a 14-day evaluation without written consent; higher usage needs agreement. The terms also require removing acquired data from website pages on termination. Verify the intended AI-app display and retention use case. |
| [Jooble REST API](https://help.jooble.org/en/support/solutions/articles/60001448238-rest-api-documentation) | Keyed keyword/location search, radius and minimum salary; German listings require a key from the [German domain](https://de.jooble.org/api/about), separately from every other country. Free plan is **500 requests total per key for its lifetime**, not monthly. | [Jooble says](https://jooble.org/api/about) results can be displayed on one's website. Confirm an app/AI-answer use case and paid quota before relying on it. |
| [Careerjet Publisher API](https://www.careerjet.com/partners/api) | Keyed `GET https://search.api.careerjet.net/v4/query`; `locale_code` (for example `de_DE`), keyword, location, radius, contract/work-hours, page and excerpt/salary fields. | [Publisher account](https://www.careerjet.com/partners/publishers) required; sends actual end-user IP and user agent, plus page Referer in its [examples](https://www.careerjet.com/partners/api/python). Designed to display Careerjet listings and earn referral revenue. Public fixed API price/free quota was not found. User-IP sharing and attribution/tracking need privacy review. |
| [Idealist Listings API](https://api-sandbox.idealist.org/listings-api) | **Real search-data feed**, unlike its posting API: `GET /api/v1/listings/jobs?since=…`, then `/jobs/{id}` for description, country, remote zone, salary and apply URL. International social-impact listings can be filtered locally for Europe. | Production key is issued manually on request. The official docs require approved Idealist logo attribution, sequential requests at least 250 ms apart, and incremental fetching. Its [general terms](https://www.idealist.org/en/terms-of-service) prohibit automated scraping and republishing without the API arrangement. Strongest mission-focused partnership candidate, but not key-free. |

## Commercial aggregators to evaluate if broad coverage is required

| Source | Search, economics, provenance | Decision point |
| --- | --- | --- |
| [OpenWeb Ninja JSearch](https://www.openwebninja.com/api/jsearch) | Direct `GET /jsearch/search-v2` (also sold through RapidAPI); `country=de`, `language=de`, location text and `work_from_home=true` are documented. Response includes publisher, job description, dated posting, source/apply links and salary **only when posted**. Vendor advertises real-time Google-for-Jobs/public-web acquisition, which is a freshness claim, not independent proof that each result remains open. Direct prices shown: free 200 requests/month; $25 for 10,000, $75 for 50,000, $150 for 200,000; pay-as-you-go $0.005/request. | Its broad board coverage comes from scraping/Google results, not a direct LinkedIn/Indeed jobseeker licence. Validate source attribution, downstream display rights, duplicates, expiration and actual DE/EU quality before using results in an AI app. RapidAPI route has separate platform constraints; vendor says direct and RapidAPI expose the same API shape. |
| [TheirStack Job Search](https://theirstack.com/en/docs/api-reference/jobs/search_jobs_v1) | Keyed `POST /v1/jobs/search`; country/location, title, remote, salary and recency filters; normalized description, source and apply fields. Requires a date or company filter; charges **one API credit per returned job**, including repeat reads. Its [free-plan update](https://theirstack.com/en/product-updates/2025-10-23-free-plan-update) states 200 API credits/month; current [paid pricing](https://theirstack.com/en/pricing) starts at $49/month for 1,500 credits, then $100/5,000 and higher tiers. Its large multi-source coverage and freshness are vendor claims requiring sample validation. | [Terms §4](https://theirstack.com/en/docs/legal/terms-and-conditions) explicitly allow public job-post display and partial integration, but bar a competing primary data service and impose downstream-use restrictions. They expressly disclaim a guarantee against third-party source-rights claims. Assess AI responses, caching, and whether job data is the app's primary value before purchase. |

## Mission-focused boards without an anonymous reuse licence

| Board | What was verified | Integration route |
| --- | --- | --- |
| [Probably Good](https://jobs.probablygood.org/) | Public board has country, remote, cause, salary and experience filters, including global roles. Its [terms](https://probablygood.org/terms-of-service/) explicitly prohibit robots and other automatic access, as well as commercial use and republication without consent. An observed browser search call would not grant an API licence. | Ask for an authorised feed/permission; do not run an automated adapter against the public site. |
| [Idealist](https://www.idealist.org/en/jobs) | Global nonprofit board and the partner Listings API described above. | Request the manually issued API key and agree to branding/terms; no anonymous scraping. |
| [GoodJobs Germany](https://goodjobs.eu/alle-jobs/deutschsprachige-jobs) | Public German social/sustainability job search with remote and SDG filters. Logged-out `/jobs` serves structured HTML and a Schema.org `ItemList`, but no official search API or reuse grant was located. Its [visitor terms](https://goodjobs.eu/terms-of-use) cover unregistered visitors, reserve content/database rights, and require written consent before making supplied content available to third parties; its [employer terms](https://goodjobs.eu/agb) additionally prohibit automated extraction. | Seek a publisher partnership rather than building a third-party feed from site HTML. |
| [Climatebase](https://jobs.climatebase.org/) | Climate jobs include European locations. Its [terms](https://jobs.climatebase.org/terms-of-use) reserve member use for personal purposes unless expressly approved and limit automated access. No public licensed search feed found. | Obtain written approval for syndication. |
| [tbd.community](https://www.tbd.community/de) | German impact-job board; [contact page](https://www.tbd.community/de/kontakt) invites partnership queries. No documented public listings API or reuse permission was established. | Request a feed/partnership. |
| Successif | A current first-party job board, API, or governing reuse terms under this name could not be verified. | Do not present as an available source until the exact organisation/site is identified. |

Major commercial boards are not substitutes for these APIs: [StepStone JobFeed](https://api.stepstone.com/wp-content/uploads/2025/03/Stepstone_JobFeed_EN.pdf) moves employer ads **into** StepStone; [Indeed's partner catalog](https://docs.indeed.com/api-guides/) centres on job posting and candidate/applicant flows (its [publisher plugin](https://docs.indeed.com/) is a different, controlled display route); [LinkedIn Job Posting API](https://learn.microsoft.com/en-us/linkedin/talent/job-postings/api/overview?view=li-lts-2026-04) is approved-partner posting, with new partnerships currently closed. [XING's API](https://help.xing.com/hc/en-us/articles/31499181417885-Which-API-interfaces-does-XING-offer) publishes employer ads and monitors them; [JOIN's API](https://join.com/de/produktneuigkeiten/make-integration) automates recruiting. No open third-party jobseeker search API was verified for either. Their public web results/internal endpoints should not be treated as durable licensed data feeds.

**Practical next access order:** keep the bounded integrated sources; request France Travail's now-restricted access with the AI use case stated; ask Idealist for its official mission-job feed; evaluate Adzuna, Jooble or Careerjet where their country and display terms fit. Use JSearch/TheirStack only after sample quality and source-rights review. Public pages from impact boards remain discoverable links until their owners authorise reuse.
