# Events

Search known official conference schedules: GPN24, 39C3, 38C3, and 37C3. Name the conference and optionally a session topic. Results link to the original schedule. General city and online event discovery are unavailable.

## How to Use It

- "Find security sessions at 39C3"
- "Show the GPN24 schedule"

Check the original conference page for current schedules and registration details.
