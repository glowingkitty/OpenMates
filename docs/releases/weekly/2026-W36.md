# Weekly Release Summary: 2026-08-31 to 2026-09-06

Generated from `400` structured change items. The companion YAML remains the source for deterministic tooling.

## Overview

OpenMates significantly advanced its agentic capabilities this week, headlined by a major overhaul of the assistant speech system and the introduction of support for the OpenAI GPT-6 Astra model. The project introduced unique vocal profiles for different Mates, progressive audio playback, and historical speech navigation via a new waveform player. Security was also a primary focus, with the implementation of granular API key scopes and isolated session security states. Additionally, application previews and model preference synchronization were refined for better reliability across multi-device sessions.
