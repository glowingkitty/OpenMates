# Weekly Release Summary: 2026-11-02 to 2026-11-08

Generated from `515` structured change items. The companion YAML remains the source for deterministic tooling.

## Overview

OpenMates achieved a major architectural milestone this week by landing a shared Rust core that now powers the npm and Python SDKs, while simultaneously migrating core web services into a high-performance shared worker. User-facing updates were headlined by the introduction of live voice dictation, assistant-authored result embeds, and interactive HTML visuals. The project also introduced granular AI server region preferences and specialized focus modes for professional workflows, alongside significant refinements to mobile event discovery and data table interactivity.

## Released Changes

- The npm and Python SDKs now utilize a shared Rust core via native bindings and WASM, ensuring consistent behavior and improved performance. (c56f31d76e, 4ecf9bf7a7, 657506743e)
- OpenMates added support for streaming voice dictation directly into the message composer editor. (c5f7cae5d7)
- Assistant-authored result embeds were introduced, allowing the AI to generate structured visual components for financial data, calendar events, and media titles. (fd90c824d9)
- Code embeds now support live sandboxed interactive HTML visuals for real-time rendering of assistant-generated web content. (b2e821a1d9)
- AI model selection now includes server region flags, supporting an EU-first hosting policy and fastest-available routing. (2d89714338, 445a598812)
- New focus modes for 'Plan Conference Talk' and 'Price Products' were added to provide specialized assistance for these workflows. (e536c40901)
- Event cards were upgraded with server-side geocoding, richer grounded descriptions, and a functional carousel for mobile devices. (257681f667, 4733976b8d)
- A new high-performance chat sync feed over WebSocket was introduced, supporting incremental updates and faster cold-starts. (cb8beb2bae, 8c16210575, 4c8d41e274)
- The web interface now features a compact ranked chat context menu with full parity to the primary action menu. (2c4a3bddff)
- The SDK root client was restricted to API-key only access to ensure strict isolation from CLI logins. (39f78b1dee)
