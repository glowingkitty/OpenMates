# Weekly Release Summary: 2026-09-28 to 2026-10-04

Generated from `314` structured change items. The companion YAML remains the source for deterministic tooling.

## Overview

OpenMates expanded its core AI and hosting capabilities this week, introducing support for the GPT-6.1 Sol model and ElevenLabs v4 speech models. The chat composer was enhanced with the ability to search saved and recent embeds, while the Hosting app added Gandi domain search integration. Significant effort was also directed toward security hardening for signups and account management, alongside extensive infrastructure work to support upcoming agentic storage and workflow features.

## Released Changes

- Support for the GPT-6.1 Sol model was added across the backend and web application. (3ce91c097)
- The chat composer now supports searching through saved and recent embeds for faster context retrieval. (b0c9e12ae)
- Support for ElevenLabs v4 speech models has been added to the audio service. (bc0615e12)
- Gandi domain search was integrated into the Hosting APIs, allowing users to check domain availability directly. (76b0f34b3)
- Guest users can now view their daily usage allowance percentage for better visibility into free limits. (1ad45d47d)
- Independent Apple Watch push targets can now be registered to improve notification reliability on wearables. (0b8108f0d)
- The CLI now supports searching project filenames and connecting explicit project sources without a full repository scan. (0e018935a, 97724fa62)
- Inline ratio formulas are now correctly rendered within chat messages. (a1307f66e)

## Bug Fixes

- Chat reliability was significantly improved by implementing recovery for failed assistant replies and automated alerts for failed chat turns. (5090e8bf6)
- Security for passkey signups and account deletions was hardened by requiring email proof and password verification. (e01bcb25b, df462e81b, e2c6e21ff)
- AI model responses are now better grounded in the current catalogue and include core capabilities in recent model contexts to ensure accuracy. (9d4b5d952, a1b291ddd, beaab0d62)
- Synchronization of draft messages across different web clients was repaired, and stale draft shells were removed. (df03ac082, cd70270b6)
- A regression was fixed where mobile header controls were hidden for signed-out users. (dacd8ad51)
- Automatic assistant speech playback functionality was restored for a smoother voice experience. (cf7c426b3)
- Security vulnerabilities in core JavaScript, Rust, and Python dependencies were patched to ensure platform safety. (b4b3ac9ae, 33030e4fe)
- The login process now accepts formatted authenticator codes, improving compatibility with various TOTP applications. (e6ca3b324)
- Location search terms are now correctly preserved when transitioning from the search view to the map view. (51945cc96)
