# Daily Release Summary: 2026-11-10

Generated from `70` structured change items. The companion YAML remains the source for deterministic tooling.

## Overview

OpenMates introduced a significant new design capability with the embroidery skill, allowing users to convert vector graphics into machine-ready files. The update also brought a manual slides editor to the web, enhanced assistant memory management, and refined image generation workflows with versioning and improved previews.

## Released Changes

- OpenMates added an embroidery skill that converts vector graphics to machine files using Ink/Stitch in a sandbox. (2b64dbec67)
- Embroidery results now feature obvious download options and previews that accurately reflect light thread colors. (aa1f0308b3)
- Embroidery results now display sewing time and thread length estimates. (751a56d90e)
- A manual slides editor is now available on the web, powered by the Rust client core. (44a462aa65)
- Manual deck edits are now saved as new server versions, and the editor uses refined round icon buttons. (02af2dfda5)
- The deck format now supports notepad text and hidden flags, with core operations for both. (fa6c5f1e1c)
- A presenter view has been added to the web interface, driven by the Rust core deck model. (520080dcf4)
- Assistant-created decks now utilize diff editing for improved efficiency. (1c94e56d88)
- The assistant can now save Memories through client-applied write jobs. (c8bcf3c321)
- The client core and CLI now support applying and undoing assistant memory writes. (c75d22343b)
- New focus modes were introduced for CV creation, job applications, and interview preparation. (c5cf9acf5a)
- Job search now supports operator-installed providers via provider aliases. (f1eae9f47c)

## Bug Fixes

- Embroidery tasks now support a 10-minute execution limit, and skills can reference graphics created earlier in the same assistant reply. (ac378c95bc)
- Embroidery downloads now decrypt correctly in the browser and feature readable titles and an improved card layout. (27d9d16e47)
- Generated image previews now display the full picture instead of a 600x400 crop. (5c1ab3c086)
- Image change requests correctly start from the referenced graphic and always trigger a new generation call. (7ee3ac00b3, 5adc8d7b3e)
- Live SVG drafts are now drawn on the active skill card during the generation process. (c1a9d701f7, 7769c13746)
- Memory suggestion previews now retry once on lost connections and avoid duplicate billing. (9859544140)
- Job-search focus modes correctly handle privacy placeholders and avoid inventing interview answers. (fb934cdabe)
- Relevance ranking now applies correctly when multiple job sources return full result lists. (2b793ea558)
- Fixed a hang occurring during the first message send after login when the Rust client core is enabled. (401faa71fe)
- Closed draft chats now remain closed, and planned shared worker stops are no longer logged as crashes. (6b19c99b70)
- The chat sidebar on mobile devices no longer displays unnecessary header profile and gift icons. (e77fa90ad3)
- The composer sensitive-data preview now correctly ignores mention chip labels. (dd0f67a974)
