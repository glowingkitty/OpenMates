## Bug Fixes

- OpenMates updated the embroidery skill to decrypt downloads in the browser and read generated SVGs through owner-bound media indices. (27d9d16e47, 3cc5d6fc59)
- Image generation cards now re-resolve correctly when waiting for versions, and previews show the full picture instead of a cropped view. (e6782b1e25, 5c1ab3c086, c1a9d701f7)
- Job-search focus modes now correctly handle relevance ranking and treat privacy placeholders as real values. (2b793ea558, fb934cdabe)
- The web app fixed issues where the first send after login could hang and draft chats would fail to stay closed when using the Rust client core. (401faa71fe, 6b19c99b70, 5ca9592e6d)
- App skill embeds are now prevented from rendering directly in assistant answer bodies, ensuring only results are shown. (0a57ce9665)

## Unreleased Progress
