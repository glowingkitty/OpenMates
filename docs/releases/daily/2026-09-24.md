## Overview

OpenMates focused on search relevance and audio efficiency today, introducing on-demand assistant speech generation and relevance-based ranking for repository and 3D searches. Significant work also went into event search quality and stabilizing unreleased Apple platform clients.

## Released Changes

- Assistant speech generation has transitioned to a demand-driven model, where audio is produced only when a user initiates playback. (a8c379909)
- Relevance-based ranking is now active for repository and 3D model searches, moving away from simple chronological or unranked results. (24c49f1b6)
- The events app now utilizes provider-specific routing and deferred metadata enrichment to decrease search latency. (2a598990c, 68c39e1f0)
- News search relevance was refined by omitting weak result padding. (d7843f0ac)

## Bug Fixes
