# Daily Release Summary: 2026-11-11

Generated from `61` structured change items. The companion YAML remains the source for deterministic tooling.

## Overview

OpenMates focused heavily on the cross-platform migration to a shared Rust client core, alongside significant advancements in AI image generation safeguards and embroidery design geometry. Work also progressed on integrating Projects and Workflows more deeply into the chat experience.

## Released Changes

- None

## Bug Fixes

- Image fullscreen views now utilize the full available screen dimensions, and tapping an image correctly opens the source file in a new tab. (788e8aa2cb)
- Resolved issues where assistant names failed to resolve in chat; authored result groups now use standard views and event cards include venue maps. (3f3c8db298)
- Embroidery design logic was corrected to prevent separate shapes from being joined by unintended stitches and to ensure sewing widths match user requests. (433c8492d9, edca0a3641)
- The web interface no longer flashes raw message source before rendering, and several console errors related to memory migration and draft deletion were resolved. (9387c8f073, 35afed7a0e)
- Privacy protections were strengthened to ensure personal data redaction does not inadvertently rewrite embed references for uploaded files. (35dbf89f93)

## Unreleased Progress

- Significant progress was made on the Apple client core migration, including UniFFI bridging, encrypted cache records, and batched decryption for chat metadata and message windows. (3d1c5cf4e1, 5ec99227f1, fbd4396131)
- AI image capabilities were expanded with Recraft V4.1 Flash for text-only drafts, a new safeguard model for named-person prompts, and server-side support for image enhancement jobs. (662f5ab4f2, c6370d9b97, 32b672579c)
- Project integration was enhanced with new activation cards in chat, support for application files within project folders, and file management operations (rename/delete) in the Rust core. (bd1e6ed0a8, f007d2e389, 01acb8e246)
- Workflows and Memories received UI updates, including a list-based memory editor and the ability to access the regular workflow editor directly within chat. (b84bb098b8)
- The design engine now supports sewing drawn lines as satin bands, improving the quality of embroidery output for outline-based geometry. (3fab01e191)

## Internal Progress

- Initial planning and architectural measures were established for the staged migration of the backend from Python to Rust. (b92fde98ca, cb332e3a8e)
- New tooling was implemented to automatically close idle Claude chat processes after three hours of inactivity to optimize resource usage. (f86aaa8b46, 8927917d05, fbca809d32)
- CI and build pipelines were updated to handle heavy type-checks more efficiently and to manage Rust core bundling across production web builds. (2a1c89c814, bf964a9c71, 06da1b2448)

## Quality Notes

- The project is prioritizing architectural consistency by moving critical logic (session management, encryption, and paging) into a shared Rust core used by both Apple and Web platforms.
- Privacy remains a focus with fixes to PII redaction logic ensuring it does not break functional embed references.
- Performance improvements were noted in Apple message rendering, reducing redundant rebuilds during decryption.
