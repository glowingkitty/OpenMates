# Daily Release Summary: 2026-11-02

Generated from `105` structured change items. The companion YAML remains the source for deterministic tooling.

## Overview

OpenMates reached a major architectural milestone by landing a shared Rust core that now powers both the npm and Python SDKs. This update also introduced live voice dictation for the web composer, a new high-performance chat sync feed, and significant refinements to the Rust-based CLI and TUI.

## Released Changes

- OpenMates added support for streaming voice dictation directly into the message composer editor. (c5f7cae5d7)
- The npm and Python SDKs now call a shared Rust core through native bindings and a portable WASM build, ensuring consistent behavior across environments. (c56f31d76e, 4ecf9bf7a7, 657506743e)
- A new chat sync feed was introduced over WebSocket, supporting incremental updates and faster cold-starts for capable clients. (cb8beb2bae, 8c16210575, 4c8d41e274)
- The web interface now features a compact ranked chat context menu with full parity to the primary action menu. (2c4a3bddff)
- The API now supports an opt-in for detailed chat metadata in batch requests, optimized for the Rust client. (0b9c94c74e)

## Bug Fixes

- OpenMates resolved a batch of reported issues in the AI and Nutrition apps, including recipe search coverage, debug decryption, and Edamam rate-limit throttling. (c3f6b42619, 7b84286b16)
- The project now suppresses chat response emails and push notifications when the final reply successfully reaches an awaiting CLI or SDK socket. (2ac08af0dd)
- The public /v1/docs API now correctly serves the documentation tree. (328ee16429)
- Device pairing approval is now securely bound to the rotated session credential. (6f7e9d38bd)
- A fix was implemented to ensure follow-up messages continue sending even when the chat recovery epoch is inactive. (8bd7337fd5)

## Unreleased Progress

- Internal work continues on the Rust core web adapter, including new worker dispatcher modules and Vite build integration. (8df408dbc8, 0180250adc, 37fc662790)
- The Rust CLI added support for project file management, focus settings, and source removal, though the Projects platform remains disabled. (849d15fed5, de00c342cd, 66978be1f3)
- Development progressed on linking OpenMates Tasks to Claude Code sessions, pending the enablement of the Tasks platform. (aef49a7d8d, 3de6434413, 06d7b980ca)

## Internal Progress

- OpenMates migrated its internal agent harness to Claude Code, retiring the previous Linear and Codex-based workflow tooling. (9b6de93671, a3472ff252, e913ef1825)
- The CI pipeline was consolidated into a single cached Rust pipeline, with new isolated lanes for building Python and WASM SDK artifacts. (f0c5897604, 748a36a31e, a3fab1ec34)
