Generated from `83` structured change items. The companion YAML remains the source for deterministic tooling.

## Overview

OpenMates focused on AI processing reliability, CLI asset management, and refining the precision of Health and Event skills. Key updates include enhanced recovery for AI preprocessing failures, new CLI commands for downloading generated files, and expanded support for Astra reasoning models.

## Released Changes

- OpenMates CLI added the ability to download generated app skill files and retrieve code run artifacts when live streaming is unavailable. Account output was also made more readable. (e6676605e, 885c8ebb4, b04ce30b0)
- AI processing now features improved completion recovery across consent prompts, better timeout detection for streaming responses, and optimized routing for Astra reasoning tools. (fe098001a, c203154e1, 9767f60af)
- Memory consent requests were converged across web and CLI clients to provide a consistent privacy experience. (623274de5)

## Bug Fixes

- The Health app received several precision updates, including better preservation of appointment request identifiers, exclusion of preventive visits and condition treatments from general searches, and improved provider eligibility checks. (670c9c712, 40b889891, a6f38ecb6)
- Events search now preserves date bounds more accurately using timezone annotations. (a9efbf0ee)
- Mindmap embeds were refined to preserve zoom controls in compact views and hide source JSON in fullscreen mode. (1b5be4e5f, 383bf1b51)
- General UI improvements include better handling of microphone permission warnings, initialization of fork title versions, and a requirement for an accepted chat turn before showing model selection. (8e0d23634, 4b427518b, 4bc366a34)

## Unreleased Progress
