## Overview

OpenMates introduced support for the OpenAI GPT-6 Astra model and implemented several refinements to the voice messaging and guest user experiences. This update also includes significant internal work on dependency security and the foundation for upcoming task activity features.

## Released Changes

- OpenAI GPT-6 Astra is now available as a selectable model within the AI application. (41d540fe2)
- Guest users can now utilize the model selector for ephemeral chat sessions without authentication. (3a7a2b69f)
- Voice recordings now finalize and render correctly within the chat message immediately after being sent. (7f1a74d9c)
