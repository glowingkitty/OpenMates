## Overview

OpenMates introduced significant enhancements to Travel and Shopping capabilities while migrating core web application logic—including draft management, history paging, and cryptography—to a Rust-based core. The update also refined AI routing for attachments and improved the reliability of collaborative web form filling.

## Released Changes

- OpenMates added support for mixed travel routes, allowing the system to compose trips using owned passes and ticket segments to find better fares. Hub-based searches were also optimized to fit within skill timeouts. (5c86344ff5, ae4f552e5c)
- The shopping experience now includes a price comparison engine that aggregates total costs (including shipping) across providers. Results are now presented as clickable offer links rather than static tables. (e56212be24, 12e49db929, 3345264306)
- The web application now utilizes a Rust-based worker core for managing socket chat frames, paging chat history, and handling draft saves. This update also enables Rust-powered cryptography and synchronized decision-making for improved performance and offline stability. (b8805f01cc, 48cc55dd80, 76fee1e26d)
- AI routing was refined to better handle image uploads and attachments, ensuring that near-threshold applications are correctly identified even when metadata is limited. (27975565f5, b1ade219d5, 5556549b04)
- The slides interface was updated to ensure presentation views and the phone remote correctly overlay the fullscreen top bar. (fd2b2b25aa)

## Bug Fixes
