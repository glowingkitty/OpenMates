## Overview

OpenMates introduced a new system for structured AI result authoring and significantly optimized web browsing startup. The update also focused heavily on voice call reliability and mobile composer stability, alongside a dev trial for offline privacy detection.

## Released Changes

- OpenMates added a source-independent typed result authoring system. This allows the assistant to generate structured, rich-media embeds across various categories like business, health, and travel regardless of the data source. (c5831accf)
- The project now supports isolated, one-owner browsing sessions designed for fast startup, reducing the wait time when using web-based skills. (612c62f6d)
- A trial for offline personal data detection was added to the developer web composer, allowing for local privacy checks before messages are sent. (d0b63e7fc)

## Bug Fixes

- Voice call reliability improved with fixes for iPhone connectivity, automatic cleanup of empty failed call sessions, and better handling of microphone permissions. OpenMates also now preserves natural thinking pauses during assistant speech. (09d92f332, 810626d47, 8ec508077)
- The message composer and draft system were stabilized to prevent content loss during voice recording or send failures. Mobile users now have a dedicated camera shortcut and more consistent attachment controls. (2ed54c9f5, 77b3ebf9f, 7119a78e9)
- Web application startup was restored for hosted environments, and new security protections were enforced for the Brotli runtime to guard against known vulnerabilities. (3a4f7aa97, cd3704074, 8cd2ec444)
- Web browsing stability was enhanced by ensuring browser windows settle correctly and sessions resume properly after being paused. (5a6e9244a, bd333ac5d)
- UI refinements include a new fade effect for the compact audio recording waveform and corrected icon colors in the chat timeline. (d6ad5a53b, b29af1873)
