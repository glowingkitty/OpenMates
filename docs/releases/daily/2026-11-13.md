Generated from `126` structured change items. The companion YAML remains the source for deterministic tooling.

## Overview

OpenMates implemented a privacy-centric update to the Memory system, masking sensitive details with client-side placeholders. The project also reached a major milestone in its web architecture, migrating six core subsystems—including search, caching, and WebSocket management—to the Rust-based shared core. Additionally, agentic coding features were improved with integrated video playback for test results and better dependency management.

## Released Changes

- OpenMates now masks sensitive details in stored Memories using client-side placeholders before they are transmitted to the AI. (c8a17d4380)
- Project Memories now support 'Ask first' and '@Mention' functionality, matching the behavior of personal Memories. (e6a416b33f, ee0b6d6e9f, f146e0bccc)
- Web test result cards now support playback of recorded test videos and preview frames. (912a4b2f67, 437aa3714b)
- The web application now uses the Rust core for search, IndexedDB persistence, WebSocket lifecycle, and workspace management. (aabaaf74c9, c17164fa5b, b6af4d0c38)
- The CLI and terminal UI now automatically include active Project Memories in every turn. (ee0b6d6e9f)
- The daily meeting briefing now includes production growth metrics via a new aggregate admin endpoint. (c83de9c2be)
