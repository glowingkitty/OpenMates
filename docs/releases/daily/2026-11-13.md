# Daily Release Summary: 2026-11-13

Generated from `126` structured change items. The companion YAML remains the source for deterministic tooling.

## Overview

OpenMates introduced significant privacy enhancements for Memories, refined the voice call experience, and improved the visibility of agentic coding results. A major internal milestone was reached with the migration of core web application logic to the Rust core. Work also progressed on unreleased orchestration features and Apple platform parity.

## Released Changes

- OpenMates now protects sensitive data by keeping real details in stored Memories and using placeholders when data is sent to the AI. (c8a17d4380)
- Project Memories now support 'Ask first' and 'Mention only' permissions. The CLI and terminal UI now support binding new chats to specific Projects. (e6a416b33f, ee0b6d6e9f)
- Gemini 4 Carbon is now available for @mentions across the CLI, TUI, and Rust core. (d63fcca1cb)
- Unfenced application script files are now automatically treated as Project files. (6e93e37f66)

## Bug Fixes

- The first call turn in a new chat now plays a neutral system voice and chime instead of a guessed Mate voice. (21372775f6)
- Voice calls now use the selected Mate's voice from the first word and accurately highlight spoken words. (f681e015e6)
- Recorded test videos and preview frames can now be played directly within the web test result cards. (912a4b2f67)
- Test run evidence is now stored correctly under test result embeds to ensure video links resolve properly. (92419d9563)
- Assistant replies now consistently include test results for coding turns, including those requiring dependency installation. (5dbcdbf621, 437aa3714b)
- Deleting a chat now correctly frees its AI context slot, preventing new chat refusals. (564926cf30)
- The web source now respects site terms that forbid automated data collection. (aec57d7b3c)
- Concurrent artifact storage by different clients of the same account no longer causes turn refusals. (2cdf27c60b)
- Rejected project operations no longer block subsequent writes or turn completion. (8c770a3ddf)

## Unreleased Progress

- Development continued on Apple platform parity, including macOS core linking, project file entries, and test-result previews for iOS. (7127adf367, 07addd1b93, bcc20ba144)
- New orchestration features are in progress, allowing chats to coordinate other main chats and handle automatic interpreting turns during active calls. (e835939a16, c88dd5f969, dd50cc1235)
- The project is preparing file editing capabilities for docs, sheets, and code within Project folders, along with new focus mode suggestions. (7512c73eb1, 4ef635ec3d)
- Event search capabilities are being expanded to include public web pages and official schedules with usage-based billing. (d114c85b2b, 722732024d)

## Internal Progress

- OpenMates completed a major migration of web application logic to the Rust core, including cache decisions, WebSocket lifecycles, workspace requests, and search. (aabaaf74c9, c17164fa5b, b6af4d0c38)
- A new read-only aggregate admin endpoint now provides production growth metrics for briefings. (c83de9c2be)
