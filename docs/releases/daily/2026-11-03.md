# Daily Release Summary: 2026-11-03

Generated from `103` structured change items. The companion YAML remains the source for deterministic tooling.

## Overview

OpenMates introduced assistant-authored result embeds and live interactive HTML visuals, while significantly improving voice call reliability and privacy controls. The update also includes a major architectural shift for the SDK to enforce API-key isolation and continues the expansion of the Rust-based core.

## Released Changes

- OpenMates added assistant-authored result embeds, allowing the AI to generate structured visual components for various data types including financial results, calendar events, and TV titles. (fd90c824d9)
- Code embeds now support live sandboxed interactive HTML visuals, enabling real-time rendering of assistant-generated web content. (b2e821a1d9)
- AI processing was updated to produce more concise mixed-media answers with proactive enrichment from images and videos. (41db226783, 2d8d9f07d1, 5f4f23ca2e)
- Voice call reliability was improved with faster speech start times, word-by-word spoken text highlighting, and live transcripts that handle thinking pauses more effectively. (29ee7065e3, 163e051198, 3752da59ea)
- A new session owner consistency layer was enforced for browser writes, and a Rust-based web auth lane was introduced behind a feature flag. (f24763eac6, cd767f7058)
- The SDK root client was restricted to API-key only access to ensure isolation from CLI logins, and app-skill bindings were regenerated for better cross-SDK conformance. (39f78b1dee, 8dd9f013b9, d41fd28e4d)
- The chat 'More' menu now pages actions five at a time for better navigation on smaller screens. (ebcd865d31)
- The Rust CLI now supports a wider range of chat management commands, including file handling, forking, and recovery parity. (893b910a56)

## Bug Fixes

- The PII detection banner was made more compact, and the message draft now remains open when interacting with PII highlight or undo actions. (5dec50a9c5, 3dc3a8812b)
- Automatic cross-chat summaries are now gated behind live Project focus consent. (2bd04c4bef)
- Empty voice-call chats are now automatically deleted after interrupted calls, including when CLI or native clients are connected. (51967fb973)
- Phased-sync now includes typed retryable errors with silent client backoff to improve connection stability. (a752e1b4af)
- Inline math parsing was corrected to close before spaced numbers, preventing incorrect currency interpretation. (cc53ef26be, 856982889f)
- IndexedDB connections are now closed on version changes to prevent multi-tab logout processes from hanging. (2435d69409)
