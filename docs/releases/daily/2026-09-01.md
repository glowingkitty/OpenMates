Generated from `107` structured change items. The companion YAML remains the source for deterministic tooling.

## Overview

OpenMates significantly advanced its audio experience today with the introduction of unique voices for different Mates, progressive speech playback, and expanded multilingual support for assistant acknowledgements. The update also includes a security improvement for the OpenCode CLI and a massive internal transition renaming 'contracts' to 'specifications' to better align with the project's development standards.

## Released Changes

- OpenMates added unique assistant speech voices, allowing different Mates to have distinct vocal profiles. (2dfdcd28e)
- Assistant speech playback is now progressive, allowing audio to begin playing while the response is still being generated. (e46272ee1)
- Prerecorded assistant acknowledgements are now available in English, Spanish, French, and German. (44c1d5d9a, dc1a6dbff, 468c3a4c9)
- The OpenCode CLI now isolates account storage for improved security. (07709518d)
- Application preview thumbnails now auto-start when a chat activates. (ab56c21e1)
- Composer button shadows were refined for better visual consistency. (ef2f5dd73)
