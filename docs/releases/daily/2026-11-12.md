# Daily Release Summary: 2026-11-12

Generated from `135` structured change items. The companion YAML remains the source for deterministic tooling.

## Overview

OpenMates introduced significant upgrades to video generation and web browsing, added the Gemini 4 Carbon model, and expanded business-focused capabilities. Video generation now supports full audio composition, while browsing features a more robust planning engine and live progress tracking. The project also enhanced transparency with AI-generated badges and improved user control over assistant memories.

## Released Changes

- Gemini 4 Carbon added as an explicitly selectable model with introductory pricing and implicit caching. (2980c7bc0f)
- Composed videos now include voice-over, sound effects, and music, with Gemini 3.8 Flash serving as the primary author model. (c67f2375aa)
- Web browsing V2 launched with one-call starts, batched steps, and a live step view for better transparency. (343757a432)
- Business tools expanded with investor search, company ownership registers, and specialized focus modes for press releases and fundraising. (0a0cafff32, 7367cdf368)
- Assistant-saved memories can now be stored to active Projects, with web support for opening and undoing these saves.
- AI-generated badges now appear on generated images and video clips in both preview and fullscreen modes.
- Event sounds added to the web app, including a silent mode toggle and quiet window settings.
- Embeds now support Enhance and Restore actions, with a new chat row notice when an embed is updated.
- Product and stay search results are now ranked by photo relevance against user criteria.

- Turn processing now continues automatically after a user approves a memory save during a focused interaction. (9ea0596275)
