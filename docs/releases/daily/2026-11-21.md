## Overview

## Bug Fixes

- Voice call stability improved by filtering assistant speech echoes, handling retried turns without server errors, and preventing short echoes from being processed as user messages. (7e35e82849, 51a7bd2a4d, 74d445cc46)
- Notification logic now groups identical alerts with a multiplier, displays chat titles instead of placeholders, and ensures Project result notices are not replayed on tab refresh. (9c9467bd4a, 814ffbfb4d, 98d0d6d60b)
- AI model routing now avoids automatic Mistral selection in favor of Gemini or Mercury, and fixes were applied to prevent AI errors during tool calls or when handling withheld diagrams. (899ff0a382, 1f6c561737, 7f533bf892)
- Chat interface refinements ensure 'Untitled' titles are never shown and that Project chat turns maintain a persistent stop button. (7c06b4de12, d0fcc37e9c)
- Embed layout fixes prevent large previews from overlapping suggestions and ensure video embeds fill mobile screen widths correctly. (43634a6ab1, c201b31c42, acdfe47d72)

## Unreleased Progress

- Voice calls now support desktop screen sharing, 'on hold' waiting logic, spoken memory requests with timeouts, and summarized text pasting. (215c24f000)
- Start screens were redesigned to unify Chats, Apps, and Workflows with inspiration cards, improved suggestion placement, and centered grid layouts.
- The Projects workspace (unreleased) added encrypted tile descriptions, category gradients, and refined file job handling for cloud commands.
- Apple platform development (unreleased) achieved start-screen parity with web, introduced MetricKit diagnostics, and improved sidebar filtering performance.
- A one-time E2B upload consent gate was added for code execution and Project file transfers.
- Sidebar and settings overlays now feature eased animations and improved mobile positioning.

## Internal Progress

- CI infrastructure now runs real-inference tests in isolated stacks with dedicated dev keys and provides speech worker fixtures for all voice call specifications. (a1bbfa325c, 5bf4c885a1, dd0cb13605)
- Security monitoring expanded with daily vulnerability emails, automated image scans, and updates to Node.js versions across Directus and worker images. (1f6c1ca5d4, 37ad542615, e8ff7bceff)
- Development tooling now supports attaching screenshots and videos to Discord pushes and ensures working chats are woken rather than closed. (570fb9a5e1, fd4f660caa)
