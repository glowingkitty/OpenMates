Generated from `45` structured change items. The companion YAML remains the source for deterministic tooling.

## Overview

OpenMates focused on AI routing architecture, migrating voice processing to the Rust core, and refining safety infrastructure. Significant work was also completed on cloud project execution and host resource management.

## Released Changes

- OpenMates integrated Gemini Decision 1 as the primary relevance judge for AI tasks, utilizing Jev as an automatic fallback based on per-task benchmarks. (cc436131d6)
- Voice turn construction has been migrated to the Rust core, ensuring reply versions and timestamps align with server-side data. (01ac4eee8e)
- Cloud Project commands now execute within per-project E2B workspaces, with modified files automatically synced back to the project as diffs. (3b2bfc8aa5)

## Bug Fixes

- The safety strike system now suspends accounts instead of deleting them, and image uploads have been updated to follow established safety guidelines. (355ed3882e)
- AI sub-chats and async-skill continuations now maintain parent turn admission, ensuring parent responses follow sub-chat completion. (575cce0203)
- OpenMates added a retry mechanism for imitated app results when a skill is offered, improving reliability for tool-based interactions. (41c77b0b62)
- Web browsing reliability was improved with better form session continuity, clearer reporting of reached caps, and fixes for follow-up calls without explicit addresses. (2ae081c7bf, c001e8492b, 13fa08ce8b)
- Code execution updates ensure failed test reasons remain visible after long install logs and prevent identical cloud commands from running multiple times in a single turn. (39d34a4b69, 8d1cbfa8b4, e3861fc795)
- The web interface and client core now handle brief 503 errors and in-flight render plans more gracefully, preventing empty replies or failed turns during chat resets. (a5cd4aff31, 5bd4fd0e1c)
- Shopping search now correctly lists the closest offers with prices even when no offers are found in the immediate vicinity. (7d56c30e76)

## Unreleased Progress
