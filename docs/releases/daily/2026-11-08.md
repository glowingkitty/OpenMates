## Overview

OpenMates focused on significant architectural and feature advancements, including the development of PDF processing v2, the expansion of the shared Rust core for web functionality, and achieving high parity between the native CLI and npm versions. Work also continued on cross-language SDK conformance and the new Learning Mode.

## Bug Fixes

- PDF processing now correctly resolves file-name aliases in search and ensures the prefetch logic only selects pages rated by the decision model. (3a1aa55560, be1a51f531, 0f7c1ddd91)
- The native CLI received numerous parity fixes to match npm behavior, including improved error wording for unknown IDs, correct exit codes for usage errors, and aligned task history and workflow command logic. (f2acd4bc47, ec7d138b2f, 4e170c06f7)
- SDK inconsistencies across Python, Rust, and npm were addressed, specifically regarding document slugs, Wikipedia language settings, and project selector ranking. (3bba1b1950, b399dbf732, beb7c08cb5)
