# Daily Release Summary: 2026-11-06

Generated from `82` structured change items. The companion YAML remains the source for deterministic tooling.

## Overview

OpenMates focused on a major architectural migration, moving core web services like search, chat sync, and authentication into a shared Rust worker. User-facing improvements include refined unread message tracking, structure-preserving Office document imports, and local PII scanning for attachments.

## Bug Fixes

- WebSocket session authority now follows refresh-token rotation to prevent refused messages after a page reload. (376a506462)
- Send failures now trigger a visible error message in the UI instead of only a haptic vibration. (cca7eab6d4)
- PDF skills now wait for OCR processing to complete and skip duplicate dispatch requests. (d70d07f6ed, e946874353)
