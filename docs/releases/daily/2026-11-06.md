# Daily Release Summary: 2026-11-06

Generated from `82` structured change items. The companion YAML remains the source for deterministic tooling.

## Overview

OpenMates focused heavily on technical consolidation, migrating several core web services—including search, synchronization, and authentication—into a shared Rust-based worker. Significant progress was also made on local privacy features, specifically PII detection for documents, and enhancing the native Rust CLI to achieve parity with the npm version.

- None

## Bug Fixes

- Websocket session authority now follows refresh-token rotation to prevent refused sends after page reloads. (376a506462)
- The shared Rust worker no longer drops in-flight crypto calls or pending unit requests during idle retirement. (e33563e82f, c745a07fc0)
- Image embed previews were updated to show full images, generate thumbnails, and support viewing as app-skill embeds. (070c9bc4b3)
- PDF skills now correctly wait for OCR completion and skip duplicate OCR dispatch. (d70d07f6ed, e946874353)
- Chat project actions are now hidden when the projects feature is inactive. (346b7d16c3)

## Unreleased Progress

- Chat unread status logic was updated to persist until the last line of a reply is viewed in both the web and TUI clients. (9861e327eb)
- Local PII detection now supports scanning pasted documents and attached files using overlapping word windows for improved accuracy. (f05cb8ee40, 6005f4bde0)

- The message input field now displays visible error messages when a send operation fails. (cca7eab6d4)
