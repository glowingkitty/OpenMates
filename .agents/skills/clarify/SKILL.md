---
name: clarify
description: Resolve a material ambiguity that blocks the requested implementation.
user-invocable: true
---

First check whether source, tests or prior user decisions already answer the
question. If a material ambiguity remains, state the verified facts, explain
what decision is needed and recommend an option. Ask a concise question and wait
before its dependent work. Continue only clearly independent authorized work.
Do not require a fixed number of questions or reconfirm an already approved goal.

For confirmed bugs, use existing browser observations, logs or failing checks
and proceed within the approved scope. Investigate only unresolved uncertainty;
do not require a fresh failing baseline. Maintain coverage and verify the fix.
